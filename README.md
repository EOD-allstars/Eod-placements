# EOD Decision Day (staff demo)

The 2027 team reveal site: countdown, athlete code login, and the cheer and dance reveal.

**Demo code: `EOD`** (shows Mia Thompson's reveal with four teams). Nothing is saved.

## Change things
- **Countdown date, teams, logos, training times:** edit `js/teams.js`
- **Team logos:** add PNGs to the `logos` folder and point to them in `js/teams.js`
- **Videos and music:** `videos` and `audio` folders
